# Notice publishing guide

1. Go to `/admin` and sign in. If you forget your password, contact the website maintainer.
2. Enter a title, category, date, optional description, and PDF. Files must be PDFs no larger than 4 MB; use a PDF compressor if needed.
3. Select **Publish notice**, then find it under **Official Notices** on the website.
4. To remove one, select **Delete** and confirm. This cannot be undone.
5. If a session expires, sign in again. For a PDF error, check its type and size. An unauthorised account must contact the maintainer.

Do not share the password. Sign out on shared computers.
